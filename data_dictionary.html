Why some Field Size values are n/a

Text fields define a maximum character length, so a concrete size is shown. Decimal fields define precision and scale. Integer, boolean, and date/time types are stored in native formats and do not have a character-length limit; their capacity is fixed by the database type rather than a text length, so the field size is noted as n/a.
